# AI Comment Analyzer

## Overview
This project is an AI Comment Analyzer plugin for WordPress, designed to analyze and provide insights on comments made on posts.

## Features
- AI-driven comment analysis
- User-friendly interface
- Integration with WordPress

## Installation
1. Upload the `ai-comment-analyzer` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.

## Usage
Once activated, the plugin will automatically analyze comments on your posts.

## Display Options & Shortcode
The plugin provides two ways to show the AI analysis box:

- **Automatic injection**: Configure the display position from the plugin dashboard (before or after post content).
- **Shortcode**: Select the “شورت‌کد” position in the same settings screen and insert `[aica_analysis]` into any post or page to render the box exactly where you want. Shortcode output respects all other display and theme settings you configured.
